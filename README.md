# OWASP BALS - Marco de Pruebas de Seguridad

Poder profesional de pruebas de seguridad OWASP Top Ten 2021 para Kiro IDE, con scoring CVSS v3.1, mapeo de cumplimiento normativo, y automatización de evaluaciones.

## Características

- **OWASP Top Ten 2021**: 10 vectores completamente documentados
- **CVSS v3.1**: Scoring profesional de vulnerabilidades
- **Cumplimiento Normativo**: PCI-DSS, GDPR, HIPAA, NIST, ISO 27001
- **68 Items Checklist**: Verificación exhaustiva
- **25+ Payloads**: Ejemplos reales de testing
- **Reportes Profesionales**: Ejecutivos, técnicos, planes de remediación
- **Integración AWS**: Security Hub, CodeBuild, CodePipeline

## Uso Rápido

En Kiro IDE, menciona cualquiera de estos términos:

```
"Realiza una evaluación de seguridad"
"Necesito pruebas de penetración OWASP"
"Genera un reporte de cumplimiento"
"Calcula la puntuación CVSS"
```

## Metodología de 5 Fases

1. **Reconocimiento** - Recopilación de información
2. **Escaneo** - Detección automática de vulnerabilidades
3. **Pruebas Manuales** - Validación de hallazgos
4. **Análisis de Riesgo** - Priorización por impacto
5. **Reportes** - Documentación profesional
