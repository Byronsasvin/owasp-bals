# OWASP BALS - Power de Pruebas de Seguridad

Poder profesional para evaluaciones de seguridad OWASP Top Ten 2021 en Kiro IDE.

## Descripción

Marco completo de pruebas de seguridad con:
- OWASP Top Ten 2021 (10 vectores)
- CVSS v3.1 scoring
- Cumplimiento normativo (PCI-DSS, GDPR, HIPAA, NIST, ISO 27001)
- 68 items checklist
- 25+ payloads reales
- Reportes ejecutivos profesionales

## Funcionalidad

Este poder proporciona:

1. **Evaluaciones de Seguridad**
   - Análisis completo de aplicaciones web
   - Testing de cada vector OWASP
   - Identificación de vulnerabilidades

2. **Scoring de Vulnerabilidades**
   - CVSS v3.1 profesional
   - Matriz de riesgo
   - Priorización por impacto

3. **Reportes Profesionales**
   - Resumen ejecutivo
   - Detalles técnicos
   - Planes de remediación
   - Cronogramas

4. **Cumplimiento Normativo**
   - Mapeo a PCI-DSS
   - Validación GDPR
   - Requisitos HIPAA
   - Alineación NIST
   - Conformidad ISO 27001

## Cómo Usar

### Activación Automática

Menciona cualquiera de estos términos en Kiro:

```
seguridad, pruebas, testing, penetración, vulnerabilidades, 
cvss, cumplimiento, compliance, pci-dss, gdpr, evaluación, auditoría
```

### Prompts Rápidos

**Evaluación Completa:**
```
Realiza una evaluación completa de seguridad de [URL] usando OWASP BALS.
Incluye los 10 vectores, scoring CVSS, mapeo de cumplimiento (PCI-DSS, GDPR),
y un plan de remediación con cronograma.
```

**Vector Específico:**
```
Prueba este endpoint para vulnerabilidades de Inyección (A01) usando OWASP BALS.
Proporciona payloads, pasos de validación, score CVSS, impacto empresarial,
y ejemplos de código de remediación (SQL, Python, Node.js).
```

**Reporte Ejecutivo:**
```
Genera un reporte de seguridad ejecutivo para [aplicación] usando OWASP BALS.
Incluye matriz de riesgo, resumen de hallazgos, brechas de cumplimiento
(PCI-DSS, GDPR), y plan de acción priorizado.
```
